Coverage - what nothing in the library turns on

Every value is read out of the scene's own register file, so it cannot drift from what the scene actually does and it works for the VDP dumps, which are someone else's content. A value in red is reached by no scene: either a scene worth writing, or a feature this firmware does not have. The matrix cannot tell those apart, which is the point of listing them.

Reading this

The bar is the line, not the verdict. Render and line are averaged over four frames, so a scene can sit well inside budget and still drop a scanline. The DROPPED pill is the acceptance test - an over-budget line is skipped rather than drawn late, so its row holds the previous capture's pixels and is not compared at all.

Render is the library; line is everything. render times pico9918_scan_line alone. line closes after the diagnostic overlay draws, so it only compares against runs taken with the same overlay setting - which is why the record stamps it.
